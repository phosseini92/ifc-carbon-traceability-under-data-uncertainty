This independent research demonstrator is owned and presented by Parisa Hosseini.
AI-assisted coding and drafting were used during development. The project is intended
for research preparation and portfolio evidence only after the applicant independently
reproduces the workflow, inspects the source data, understands the code paths and can
explain the assumptions, tests, failure modes and limitations.

AI assistance is not treated as validation. Numerical and methodological claims must be
supported by saved execution evidence, source provenance, manual checks and explicit
boundaries. Any portfolio version should distinguish clearly between:

- the applicant's research question, scope, interpretation and methodological choices;
- software implementation assistance;
- independently reproduced execution evidence;
